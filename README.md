# AI Resume Analyzer

An AI-powered Resume Analyzer built using Python, NLP, Machine Learning, and Streamlit.

## Features

- Upload Resume (PDF)
- Resume Text Extraction
- ATS Score
- Skills Detection
- Resume vs Job Description Matching
- Job Recommendation
- Missing Skills Detection

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- NLTK
- Pandas
- PyMuPDF
